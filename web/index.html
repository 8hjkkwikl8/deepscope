它是怎么工作的

02Researcher ×N

并发检索、安全抓取、结构化笔记

流式写作 + 引用校验 + 导出

工程要点

  • 全链路 SSE：Agent 的搜索、阅读、笔记、写作事件实时可见
  • 证据闭环：编号来源贯穿笔记、写作、引用校验与导出
  • 并发编排：子问题并行、抓取限流、失败子任务隔离
  • 安全默认：URL 私网校验（SSRF）、Markdown 消毒、Key 不落盘
  • 可降级：Tavily / 360 / 搜狗 / Bing / 离线多级搜索回退

技术栈

Python 3.13FastAPIAsyncIOhttpx SSEBeautifulSoupVanilla JSMarked + DOMPurify

可讲的设计取舍

没有引入 LangChain：四角色编排逻辑透明、可控、易调试，也更适合展示对 Agent 原理的理解。搜索层做成可插拔，避免把系统绑死在单一数据源上。
